Python kullanılarak geliştirilmiş, elek analizi verilerinin değerlendirilmesini ve tane boyutu dağılımının Gaudin-Schuhmann modeli ile incelenmesini sağlayan masaüstü uygulamasıdır.

Program, Excel dosyasındaki elek analizi verilerini okuyarak kümülatif elek altı değerlerini hesaplar, Gaudin-Schuhmann eğrisini oluşturur ve istenilen yüzde değerine karşılık gelen tane boyutunu hesaplar.

## Özellikler

- Excel dosyasından elek analizi verilerini okuma
- Elek boyutu ve elek üzerinde kalan miktar verilerini kullanma
- Toplam numune miktarını hesaplama
- Her elek üzerindeki kalan miktarı yüzdeye dönüştürme
- Kümülatif elek altı değerlerini hesaplama
- Gaudin-Schuhmann modeline uygun eğri oluşturma
- D50 ve D80 değerlerini hesaplama
- Kullanıcının girdiği yüzde değerine karşılık gelen tane boyutunu hesaplama
- Elek analizi sonuçlarını grafik üzerinde gösterme
- Logaritmik eksenlerde tane boyutu dağılımı grafiği oluşturma
- Tkinter arayüzü üzerinden hesaplama yapma

## Kullanılan Teknolojiler

- Python
- Tkinter
- NumPy
- Pandas
- Matplotlib
- SciPy
- Excel
